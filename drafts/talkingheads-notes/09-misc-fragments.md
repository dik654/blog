# 09 · 소재 조각 (독립 글 아님)

## 한국어 프롬프트 문제

- **위치**: articlesAgent.ts "Qwen 한국어 일관성: 출력 누출, 추론 언어, 런타임을 분리해 고치기"에 흡수 후보.
- 어색한 표현이 나오는 이유: 번역체 학습 데이터 다수, 기술 용어의 한국어 용례 부족, 주어·목적어 생략, 모델이 영어로 구성한 표현의 직역, 긴 명사구·하이픈 구조 직수입.
- 영어 프롬프트가 지시 정확도를 올릴 수 있으나 항상 정답 아님. 실무 원칙: 모호한 한국어 → 명시적 한국어로 수정, 필요 시 내부 지시는 영어 + 최종 출력은 한국어.
- 기존 글이 "출력 누출/추론 언어/런타임 분리" 프레임이므로, 이 조각은 "왜 한국어 지시가 어색해지는가"의 원인론 단락으로 들어감.

## 대화 전체 사실판정 표 (1차 대화)

집필 시 각 노트에 이미 반영했지만 원표 보존:

| 주제 | 판정 |
|---|---|
| 체스로 RL 연구 | ✅ 사실 |
| Pretrain vs RL Scaling Law | ✅ 사실 |
| JLens는 추론을 읽는다 | ❌ 아님 |
| JLens는 후보 토큰/활성화를 해석 | ✅ 대체로 맞음 |
| Mamba는 장문 처리에 강점 | ✅ 사실 |
| Mamba가 Transformer를 대체 | ❌ 현재는 아님 |
| 하이브리드 구조가 증가 | ✅ 사실 |
| CUDA/Triton 최적화가 매우 중요 | ✅ 사실 |
| SSM이 제어공학에서 유래 | ✅ 사실 |
| Kimi·Qwen이 Mamba 파생 | ⚠️ 과장 (일부 아이디어 차용 하이브리드가 정확) |
