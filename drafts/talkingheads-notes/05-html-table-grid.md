# 05 · HTML 테이블 grid 복원 — 기존 글 보강 소스

- **상태**: **기존 글 보강** (신규 글 만들지 말 것)
- **위치**: ai/articlesOCR.ts — "HTML Table Parsing: rowspan·colspan에서 Grid Reconstruction까지" 글이 이미 존재. 대화 소재는 이 글의 사례·동기 보강용.

## 원 대화 핵심

- 병합 셀(rowspan/colspan)을 일반 격자로 복원하는 표준 파이프라인:
  HTML → DOM → rowspan → colspan → Grid 생성 → 빈칸 Backfill → 최종 Matrix.
- ✅ 실무에서 매우 까다롭고 문서 파서·OCR 후처리에서 반복 등장하는 문제.
- "임베딩 모델에 HTML째로 넣고 싶다"는 발언 = 규칙 기반 복원의 피로 → LLM/임베딩에 구조 이해를 떠넘기고 싶다는 반농담. **규칙 기반 vs 모델 기반 트레이드오프** 논의의 실화 사례로 쓸 수 있음.

## 보강 포인트

- 기존 글에 "왜 다들 결국 모델에 통째로 넣고 싶어지는가" 단락이 없다면: 규칙 기반의 엣지케이스 피로 → 모델 기반의 비결정성 비용 대비. 같은 파일의 olmOCR 2(unit test reward)·Document Assembly 글과 상호 링크 후보.

## 채우기 전 확인

- 기존 글 본문을 읽고 위 파이프라인 서술과 중복인지 확인 — 파이프라인 자체는 이미 있을 가능성 높음. 실화 사례(대화 인용)만 추가하는 수준일 수 있음.
