# 02 · "JLens" — LLM 내부 표현 해석 도구

- **상태**: 신규 글 후보 — 단, **명칭 자체가 미검증** (아래 확인 항목 1순위)
- **위치**: ai/articlesLLM.ts 해석(interpretability) 계열. Claw Code 트랙과는 별개.

## 원 대화 핵심

- "JLens"는 입력 → hidden representation → logit → token 중간 단계를 사람이 보기 쉽게 만드는 해석 도구로 소개됨.
- Attention map과의 대비가 글의 뼈대:
  - Attention: A 토큰이 B 토큰을 얼마나 봤는지 = **관계**를 보여줌.
  - JLens 계열: 지금 모델이 어떤 후보 토큰을 실제로 경쟁시키는지, 어떤 feature가 활성화됐는지 = **의사결정 후보**를 보여줌.
- ⚠️ "수십만 개 토큰이 25개 이하로 줄어든다"는 엄밀하지 않음 — vocabulary 전체가 아니라 activation/logit/candidate를 필터링해 **시각화 대상이 줄어드는 것**.
- ❌ JLens로 CoT/추론/생각을 읽을 수 있다 — 아님. 추론은 모델 내부에 텍스트 형태로 존재하지 않으므로 "왜 그렇게 생각했는지 직접 읽기"는 불가.

## 글의 각도

**"관계를 보는 도구 vs 결정 후보를 보는 도구"** 이분법이 훅. attention 시각화의 한계 → logit lens 계열의 기여 → "그래도 추론은 못 읽는다"는 경계선까지, 기대치 교정 글로.
블로그의 판독 스타일(처음 보는 도구를 어떤 질문으로 읽는가)에 맞춰: "이 해석 도구는 무엇을 보여주고 무엇을 보여준다고 착각하게 하는가"를 프로토콜화.

## 채우기 전 확인

- **"JLens"라는 이름의 실존 여부** — 대화 전사 오류일 가능성 높음. 후보: Logit Lens / Tuned Lens / Patchscopes / (SAE 기반) feature 시각화 도구. 실제 도구·논문을 특정한 뒤 명칭 교체.
- 특정된 도구 기준으로 "후보 토큰 경쟁 + feature 활성화" 설명이 정확한지 재검증 (둘은 보통 다른 도구 계열: lens류=logit, SAE류=feature).
