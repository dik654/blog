# AI 시계열 묶음 13

## 범위

- `ai/arima` — 개념
- `ai/lstm-timeseries` — 실무

## 직속 부모 지도

`예측 계약 → 해석 가능한 기준선 → 신경망 적용`

두 글은 같은 예측 시점·범위·사용 가능 정보 계약을 공유합니다. 첫 글은 ARIMA로 반복 구조를 설명하고 진단하는 기준선을 세웁니다. 두 번째 글은 그 계약을 LSTM의 윈도우·텐서·학습·평가 절차로 옮기고 추가 가치를 검증합니다.

## 변경 원칙

- 핵심 시각 자료를 각 절의 설명과 수식보다 먼저 배치합니다.
- ARIMA 글에서는 예측 계약·차분·AR/MA·시간 순서 검증·확장 조건을 설명합니다.
- LSTM 시계열 글에서는 윈도우·텐서 상태·누출 방지·동일 조건 모델 선택을 실제 적용 순서로 연결합니다.
- 장식용 자동 재생은 추가하지 않습니다. 기존 시각 자료가 상태와 경계를 정적으로 충분히 보여 주므로 움직임이 학습 정보를 늘리지 않는 곳에는 모션을 넣지 않습니다.
