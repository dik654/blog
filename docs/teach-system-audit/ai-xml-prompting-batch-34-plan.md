# AI XML 프롬프팅 묶음 34

## 범위

- `ai/xml-prompting` — 개념

## 학습 경로

`역할 경계 → 문법·직렬화 → 반복 자료 → 출력 검증 → 형식 선택`

## 변경 원칙

- 고객 이메일 한 건을 입력 조립부터 안전한 실행 후보까지 끝까지 추적합니다.
- XML 태그의 역할과 serializer·parser·schema·업무 규칙·권한 검사의 책임을 분리합니다.
- 각 절의 첫 설명보다 해당 단계의 시각화를 먼저 배치합니다.
- 장면은 실제 상태 변화만 보여 주고, 명시적으로 재생했을 때 장면당 6.2초를 사용합니다.
- JavaScript가 없어도 모든 장면의 순서와 결론을 정적 목록으로 제공합니다.
- 기존 표준·보안 근거와 상세 코드·비교 기준은 보존합니다.
