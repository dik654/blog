# 세계사 기초·장기 흐름 6편 작성 계획

## 작성 카드

- 독자: 세계사를 왕조와 사건 이름으로만 접했거나 처음부터 다시 배우려는 일반 독자
- 글의 종류: 실제 사료와 작은 숫자 사례를 함께 읽는 공개 설명 글
- 약속: 한 편을 읽고 나면 생활의 구체적인 문제에서 제도와 권력이 생기는 경로를 설명하고, 사료가 직접 보여 주는 범위와 추정을 구분할 수 있습니다.
- 다루지 않는 범위: 여섯 글을 모든 지역의 단일 발전 단계로 제시하지 않으며, 개별 지역사의 연표와 학계의 모든 내부 논쟁을 대신하지 않습니다.

## 공통 개요

1. S: 이 변화가 세계사를 이해하는 데 필요한 이유를 밝힙니다.
2. B: 3~5개의 큰 흐름을 이름 없이 먼저 나눕니다.
3. 0: 설명용 숫자 한 건을 `(가정)`으로 표시해 놓습니다.
4. 1: 숫자가 오가는 장소와 사람을 한 그림으로 엽니다.
5. 2: 각 부분이 필요한 이유와 흔한 오해를 설명합니다.
6. 3: 앞에서 본 역할에 정식 이름 세 개를 붙입니다.
7. 4: 첫 숫자 사례를 같은 값으로 끝까지 추적합니다.
8. 5·6: 실제 사료 두 건을 원문 발췌와 함께 읽고 관찰 범위를 나눕니다.
9. 7: 일반화의 한계와 예측 질문 세 개로 닫습니다.

## 검토 기록

이 개요는 기존 세계사 6편의 빈 범위를 MIT 고고학·기술사·세계사 과정과 Princeton 세계사 교재 주제에 대조해 제시한 뒤, 사용자가 최신 `teach-system`에 맞춰 계속 진행하라고 지시한 범위입니다. 2026-10-07에 v0.8의 카드·용어 지연·한 줄기·사료 경계·리듬·레이아웃 검사를 추가했습니다.
