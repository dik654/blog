## 묶음의 직속 부모

앞 묶음은 한 번의 GPU 실행을 더 효율적으로 제출하고 계산하는 방법까지 설명했습니다. 이번 묶음은 큰 모델의 순차 실행 횟수 자체를 줄이려는 방법을 두 단계로 나눕니다.

1. 확정 원리: 값싼 후보를 큰 모델이 함께 검증하고, 첫 거부 전까지의 출력과 계산 기록만 확정합니다.
2. 후보 전략: 같은 확정 원리를 유지하면서 후보의 출처와 모양을 바꾸었을 때 드는 비용을 비교합니다.
