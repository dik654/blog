## 변경 원칙

- 월드모델을 “미래 화면을 만드는 모델”로 소개하지 않고 상태·행동·다음 상태의 계약부터 보여 줍니다.
- 위치 0에서 목표 2로 가는 같은 사례를 관측·예측·실행·재관측까지 끊지 않고 추적합니다.
- 모델 안에서 여러 후보를 비교하는 과정과 현실에 첫 행동 하나만 보내는 과정을 시각적으로 분리합니다.
- 기존 LeWM·CEM 코드 대조, 표현 붕괴, 먼 목표의 한계와 수치 검산은 그대로 보존합니다.
- 첫 동작 그림은 첫 설명문보다 앞에 두며, 재생은 사용자 입력이 있을 때만 시작합니다.
