## 변경 원칙

- 생성 표본이 판별기를 거쳐 생성기 기울기로 돌아오는 한 경로를 먼저 보여 줍니다.
- 판별기 단계와 생성기 단계에서 각각 누가 가중치를 바꾸고 어느 기울기를 통과시키는지 분리합니다.
- Wasserstein 판별 함수의 제약과 조건부 생성의 평가 계약을 학습 목표가 아니라 후속 확대 단계로 연결합니다.
- 핵심 동작 그림은 용어·수식보다 먼저 배치하고, 그림의 역할 이름은 한국어를 먼저 씁니다.
- 장면은 명시적인 입력 전까지 시작하지 않으며 화면 밖에서는 정지합니다.
- JavaScript 비활성 상태에서는 모든 장면의 순서와 결론을 제공합니다.
