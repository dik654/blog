## 변경 원칙

- 다섯 글을 서로 떨어진 기법 설명이 아니라 하나의 분류 판단 흐름으로 연결합니다.
- 각 글은 직속 부모, 현재 위치, 같은 묶음의 앞뒤 글을 본문보다 먼저 보여줍니다.
- 첫 그림은 구체적인 모집단·표본·손실·비용·혼동 행렬을 사용하고 설명문보다 먼저 배치합니다.
- 학습 자료의 비율, 손실의 배점, 운영 임계값, 평가 보고서가 서로 다른 상태를 바꾼다는 점을 구분합니다.
- 장면은 사용자 입력이 있을 때만 진행하며, 화면을 벗어나면 멈춥니다.
- JavaScript가 없어도 네 장면의 순서와 결론을 정적 목록으로 제공합니다.
- 기존 수식·논문 근거·연습문제는 유지하고, 이미 검증된 세 글은 내용 대신 학습 경로와 시각화 수명주기만 보강합니다.
