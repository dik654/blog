## 직속 부모 지도

`잔차 보정 → 목적함수 → 탐색 비용 → 순서 누출 → 표현 선택`

## 변경 원칙

- 한 집의 예측을 고치는 경사 부스팅에서 시작해 구현별로 달라지는 한 축씩만 엽니다.
- XGBoost는 잎의 목적함수, LightGBM은 분할 탐색 비용, CatBoost는 순서 누출을 맡습니다.
- 표 형식 딥러닝 글은 같은 자료 분리와 탐색 예산에서 표현 학습의 추가 가치를 판단하는 실무 글로 둡니다.
- 각 글은 직속 부모, 현재 위치, 같은 묶음의 앞뒤 글을 본문보다 먼저 보여줍니다.
- 첫 그림은 설명문보다 먼저 배치하고, 장면은 사용자 입력이 있을 때만 진행합니다.
- JavaScript가 없어도 모든 장면의 순서와 결론을 정적 목록으로 제공합니다.
- 기존 수식·논문 근거·연습문제는 유지하며, 기술 이름을 장식 카드가 아니라 계산과 상태 변화에 붙입니다.
