## 변경 원칙

- 두 글을 서로 떨어진 기법 설명이 아니라 자료 증강 계약을 적용하는 같은 실무 경로로 연결합니다.
- 각 글은 정확한 부모 개념 앵커와 현재 위치, 같은 경로의 앞뒤 글을 먼저 보여줍니다.
- 표본 조합은 `두 원본 → Mixup → CutMix → Mosaic 정답`, 표 합성은 `자료형 → 관계 제약 → 학습 자료 안의 합성 → 유용성·정보 노출 검사`를 첫 그림으로 추적합니다.
- 기존 수식·논문 근거·경계 설명은 유지하고 첫 동작 그림을 첫 설명문보다 앞에 둡니다.
- 장면은 사용자 입력이 있을 때만 진행하며 JavaScript가 없어도 네 장면의 순서와 결론을 모두 제공합니다.
