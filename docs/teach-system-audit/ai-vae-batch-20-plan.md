# AI VAE 묶음 20

## 범위

- `ai/vae` — 개념

## 직속 부모 지도

`생성 모델 → 잠재변수 모형 → {숨은 원인 → 분포 추정 → 표본 만들기 → 두 비용 → 사용 여부 → 표현 변경}`

## 변경 원칙

- VAE를 단순한 확률적 Autoencoder로 소개하지 않고, 계산하기 어려운 사후분포를 근사하는 잠재변수 모형에서 시작합니다.
- 한 이진 관측의 평균·분산, 외부 난수, 잠재 표본, 복원 확률, 복원 비용과 KL을 같은 숫자로 추적합니다.
- 기존 ELBO 유도, PyTorch 원문, posterior collapse와 IWAE의 경계는 줄이지 않고 첫 장면 뒤에서 해설합니다.
- 첫 동작 그림은 첫 설명문보다 앞에 두며, 재생은 사용자 입력이 있을 때만 시작합니다.
