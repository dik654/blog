## 오탐과 개발 서버 변동 처리

- SVG의 변환 전 `getBBox()`는 회전된 글자가 잘린 것처럼 보일 수 있어 화면 좌표로 다시 판정했습니다.

- HMR로 DOM이 교체되면 좌표가 0이 되거나 실행 컨텍스트가 사라졌습니다. 전역 등록 파일의 쓰기가 멈춘 뒤 해당 route를 다시 검사했습니다.
