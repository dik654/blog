# 대학 교과과정·직무 자격 기반 내용 범위표

확인일: 2026-10-07. 이 문서는 블로그의 목차를 한 학교나 한 자격시험의 목록에 맞추기 위한 표가 아니다. 여러 대학의 교과과정, 공개 교재, 직무 자격 과정에서 반복되는 질문을 대조해 **다룬 내용·얕은 내용·비어 있는 내용**을 찾는 기준이다.

## 사용하는 기준

한 분야는 다음 다섯 층을 확인한다.

1. **입구** — 처음 보는 사람이 생활 사례와 필요한 선수 개념에서 출발할 수 있는가
2. **핵심 구조** — 대학 입문 과목과 표준 교재에서 반복되는 개념과 논증이 이어지는가
3. **실제 적용** — 문제 풀이, 사례, 코드, 계약서 또는 사료에 개념을 대입하는가
4. **역사와 제도** — 지금의 개념이 생긴 시간 순서와 국가·제도별 차이를 설명하는가
5. **경계와 최신 변화** — 반례·측정 한계·법적 범위·최근 논문이나 규정 변화를 구분하는가

글 수나 제목만으로 칸을 채우지 않는다. 각 칸에는 정본 글, 실제 사례, 핵심 근거, 복습 문제와 범위 경계가 있어야 한다. 한 학교의 강의는 강조점이 있으므로 적어도 `대학 과정 1개 + 공개 교재 1개 + 원전·공식 기관 자료`를 교차한다. 법·자격·상품 규정은 현재 공식 자료를 다시 확인한다.

## 철학 교과과정 대조

### 기준 자료

- [MIT 24.00 Problems of Philosophy](https://catalog.mit.edu/schools/humanities-arts-social-sciences/linguistics-philosophy/#24.00): 윤리·형이상학·지식론·논리·언어·과학철학을 문제 중심으로 다룬다.
- [MIT 24.01 Classics of Western Philosophy](https://ocw.mit.edu/courses/24-01-classics-of-western-philosophy-spring-2016/pages/lecture-notes/): 소크라테스·플라톤에서 아리스토텔레스, 데카르트, 흄, 칸트, 밀, 뒤부아, 보부아르까지 시간 순서로 원전을 읽는다.
- [Stanford 철학 학부 과정](https://bulletin.stanford.edu/programs/PHILO-BA): 논리, 형이상학·과학철학, 지식론, 윤리·정치철학, 역사적 뿌리를 큰 축으로 둔다.
- [OpenStax Introduction to Philosophy 공개 교재](https://open.umn.edu/opentextbooks/textbooks/1270): 철학의 방법과 글쓰기, 세계 철학사, 논리, 형이상학, 지식론, 가치론, 규범·응용 윤리, 정치철학, 현대 사회이론의 순서를 제공한다.
- [Yale PHIL 176 Death](https://online.yale.edu/courses/death): 몸과 마음, 인격 동일성, 죽음의 해악, 자살과 삶의 태도를 하나의 문제에서 형이상학과 가치론으로 연결한다.

첫 여섯 편은 `무차익 가격 → 청산과 증거금 → 옵션 복제 가격 → 그릭스와 변동성 → 금리파생상품 → 권유·분쟁·준법`의 기초 순서를 만든다. 두 번째 여섯 편은 `통화 헤지 → 원자재 곡선·인도 → 옵션 조합·구조화채권 → CDS·트랜치 → 장외 기본계약·담보·CVA → VaR·예상손실·스트레스`로 실제 운용과 위험관리 범위를 잇는다. 세 번째 여섯 편은 `회귀 기반 헤지 수량 → 이항 가격과 조기행사 → 변동성 표면 → 금리곡선 → xVA → 백테스트·손익 귀속·모형 검증`으로 계산과 통제를 더 깊게 잇는다. 네 번째 여섯 편은 `브라운 경로·이토·위험중립 → 경로 모의와 분산 감소 → PDE·유한차분·수치오차 → 지역·확률변동성·점프 보정 → 단기금리·HJM → 위험강도·회수·부도상관`으로 확률과정과 고급 수치평가를 잇는다. 다섯 번째 여섯 편은 `한국·싱가포르 진입 문 → EU·영국 CFD 보호 → 일본·호주 레버리지와 상품 유통 → 미국 관할과 고객자금 분리 → 장외 청산·보고·비청산 위험 완화 → 국경 간 상계 집행과 규제 인정`으로 주요 관할의 제도를 같은 질문에 대입한다. 여섯 번째 여섯 편은 `은행 IRRBB·ALM → 헤지회계 지정·효과·재조정 → 세금의 성격·시점·관할 → 포지션 한도·헤지 예외·시장감시 → KYC·자금경로·STR → 민원 증거·분쟁 구제`로 은행과 자격 과정의 거래 전후 업무를 연결한다. 일곱 번째 여섯 편은 `비청산 IM·SIMM → 거래 확인·결제·대사 → 담보 호출·분쟁·교체 → 상품 승인·목표시장·사후검토 → 다중자산 상관·희귀사건 표본 → 캐나다·홍콩·스위스 고객 규칙`으로 계산 결과가 계약·담보·판매·국가별 서비스에서 실제 통제가 되는 과정을 연결한다. 여덟 번째 여섯 편은 `KRX 계약·주문·일일정산 → 거래 압축 → 담보 최적화 → CCP 부도 헤지·경매·고객 포지션 이전 → 스왑션 연금계수·호가형·큐브 → 판매기록·열람·보존·파기`로 자격 과정에서 남았던 장내 실무와 거래 뒤 운영 공백을 채운다. 아홉 번째 여섯 편은 `옵션 디스퍼전·내재상관 → 신용 트랜치·베이스 상관·경매 → 원자재 품질·장소·선적증서 → 조사 감사기록·법적 보류 → 미국·영국 세무 장부 → 조각투자·비금전신탁 수익증권`으로 특수 상품의 가격 입력을 실제 인도·조사·세무·투자자 권리까지 잇는다. 열 번째 여섯 편은 `디스퍼전 하루 손익 → 실제 CDS 경매 주문과 베이스 상관 이력 → WTI 쿠싱 인도 → LME 워런트와 출고 → 축산물 실물·현금정산 → 싱가포르 기록·민원·GST`로 공개 규칙을 체결·인도·사후관리 장부에 대입한다.

자격 과정은 대학 가격이론의 대체 교재가 아니라 현장 누락 검사표로 쓴다. 파생상품투자권유자문인력 과정에서는 장내·장외 상품, 투자권유 실무, 법규·윤리·세제·AML·분쟁을 확인하고, 은행권 자산관리사(FP) 과정에서는 고객 자료·재무 목표, 금융상품·주식·채권·파생금융상품과 투자설계 절차의 연결을 확인한다. GARP는 위험모형과 운영 통제를, 대학 금융론은 무차익과 가치평가를 맡긴다. 실제 숫자와 효력은 거래소·감독기관·국제기준 원문에 다시 대조한다. 13개 과목과 보수·FP·FRM 항목별 경로는 [파생상품 교과·자격 과정 대조표](derivatives-curriculum-coverage.md)에 따로 기록했다. 다음 보강은 공개 운용 원장으로 검증한 디스퍼전 손익, 여러 신용 경매와 같은 날짜의 트랜치 호가 비교, 추가 원자재와 관할의 제재·세무, 조각투자 시장 개장 뒤 사례다.

앞으로 파생상품 글은 `대학의 가격 원리 + 파생상품투자권유자문인력의 판매·법규 범위 + 은행 FP/PB의 고객 장부 + FRM의 위험 통제` 네 축을 고정 검사표로 사용한다. 어느 한 축만 통과한 글은 분야를 다룬 것으로 세지 않는다.

지역·횡단·제도·측정 글은 한 지역을 하나의 정책 성공담이나 반복되는 위기로 만들지 않는다. 각 글은 설명용 숫자 장부를 사용하되 세계은행·중앙은행·OECD·Eurostat·WTO·ILO·정부 자료의 관찰 단위와 기관 관점을 밝히고, MIT·LSE·Oxford 과정의 질문으로 빠진 권리·생활·법·자료 유형을 다시 확인한다. 평균 생산량이나 제도 이름에서 멈추지 않고 **누가 어떤 권리와 비용을 가졌는지, 충격 전후 장부가 어떻게 달라졌는지, 생산 장소의 숫자가 주민과 국내에 실제로 얼마나 남는지, 어느 지역과 시기까지 자료를 옮겨 읽을 수 있는지**를 같은 순서로 확인한다. 다음 경제사 묶음은 국가별 상법·복지·정책금융과 지역 내부 분포계정의 실측 비교를 우선한다.
