# 대학 교과과정·직무 자격 기반 내용 범위표

확인일: 2026-10-07. 이 문서는 블로그의 목차를 한 학교나 한 자격시험의 목록에 맞추기 위한 표가 아니다. 여러 대학의 교과과정, 공개 교재, 직무 자격 과정에서 반복되는 질문을 대조해 **다룬 내용·얕은 내용·비어 있는 내용**을 찾는 기준이다.

## 사용하는 기준

한 분야는 다음 다섯 층을 확인한다.

1. **입구** — 처음 보는 사람이 생활 사례와 필요한 선수 개념에서 출발할 수 있는가
2. **핵심 구조** — 대학 입문 과목과 표준 교재에서 반복되는 개념과 논증이 이어지는가
3. **실제 적용** — 문제 풀이, 사례, 코드, 계약서 또는 사료에 개념을 대입하는가
4. **역사와 제도** — 지금의 개념이 생긴 시간 순서와 국가·제도별 차이를 설명하는가
5. **경계와 최신 변화** — 반례·측정 한계·법적 범위·최근 논문이나 규정 변화를 구분하는가

글 수나 제목만으로 칸을 채우지 않는다. 각 칸에는 정본 글, 실제 사례, 핵심 근거, 복습 문제와 범위 경계가 있어야 한다. 한 학교의 강의는 강조점이 있으므로 적어도 `대학 과정 1개 + 공개 교재 1개 + 원전·공식 기관 자료`를 교차한다. 법·자격·상품 규정은 현재 공식 자료를 다시 확인한다.

첫 여섯 편은 `무차익 가격 → 청산과 증거금 → 옵션 복제 가격 → 그릭스와 변동성 → 금리파생상품 → 권유·분쟁·준법`의 기초 순서를 만든다. 두 번째 여섯 편은 `통화 헤지 → 원자재 곡선·인도 → 옵션 조합·구조화채권 → CDS·트랜치 → 장외 기본계약·담보·CVA → VaR·예상손실·스트레스`로 실제 운용과 위험관리 범위를 잇는다. 세 번째 여섯 편은 `회귀 기반 헤지 수량 → 이항 가격과 조기행사 → 변동성 표면 → 금리곡선 → xVA → 백테스트·손익 귀속·모형 검증`으로 계산과 통제를 더 깊게 잇는다. 네 번째 여섯 편은 `브라운 경로·이토·위험중립 → 경로 모의와 분산 감소 → PDE·유한차분·수치오차 → 지역·확률변동성·점프 보정 → 단기금리·HJM → 위험강도·회수·부도상관`으로 확률과정과 고급 수치평가를 잇는다. 자격 과정과 GARP 범위는 상품 지식·위험모형·윤리·법규·분쟁을 빠뜨리지 않는 범위표로 썼고, 가격 이론과 시장 구조는 대학 금융론, 거래소·감독기관·국제기준 원문에 대조했다. 다음 보강은 다중자산·희귀사건 평가와 국가별 시장·고객보호·상계 집행 비교다.
