# ZK 개념·원문·구현 보강 기록

검토일: 2026-10-04. 공개 catalog의 실제 import 경로와 개념 그래프에서 관련 후보 51편을 대조했다. 아래 9편은 본문 전체를 열 단계로 다시 작성하거나 새로 작성했다. SP1은 별도의 사실·가독성 보강이다. 후보 51편 전체를 다시 썼다는 뜻은 아니다.

기존 소유권을 유지한 개념 40개를 재사용했다. 새 개념은 제약된 Reed–Solomon 평가 질문, 주소 선택·변화량 메모리 검사, 생성 메모리 생존량, MSM 창 크기, EVM 원시 검증 비용, 외부 증명으로 감쌀 때의 보안 경계 6개다.

Fiat–Shamir·sumcheck·유한체·곡선·해시의 일반 정본은 연결로 재사용한다. Ethereum 채택 상태는 `/cs/blockchain/ethereum-future-roadmap`, 양자 공격과 PQC/QKD는 별도 정본이 소유한다. 빠른 증명 실험과 프로토콜 채택을 같은 사실로 서술하지 않는다.

## 원문과 고정한 구현

- Groth16 §2.2: 공개 명제·증인, 건전성과 영지식의 정의.
- RFC8235 §2.2~2.3: Schnorr 응답과 검증, 해시 입력의 경계.
- Pinocchio §2.2.1: QAP의 정확한 나눗셈.
- KZG §3.2: CreateWitness·VerifyEval. Bulletproofs §3: 내적 접기. Halo: 내적 커밋먼트의 재귀 검증 적용 경계.
- FRI 원 논문: 낮은 차수 부호와 근접성. WHIR 2024-11-21 개정본: 제약된 부호와 평가 질문.
- STARK 원 논문: AIR 경계와 영지식 구성. Nova Definition 10·11, Construction 1: 완화된 R1CS·폴딩·압축.
- Twist and Shout 2025-02-27 개정본: one-hot 주소와 increment.
- Jolt: `47130f3dc9a51a7ac2754a98ff0aa31981a6b810`, 2026-10-02 커밋. `jolt/codebase/SOURCE.json`의 목록에 있는 파일만 해당 버전의 자료다. 네 함수의 원본 전체 파일, 줄 범위, 해설을 제공한다.
- ICICLE **2.8.0** 문서의 메모리 모델을 명시적으로 사용한다. 최신판에 무조건 적용되는 수치로 주장하지 않는다.
- EIP1108·EIP197: BN254 원시 연산 요율과 페어링 입력 인코딩. 전체 거래 가스와 구별한다.
- EF zkEVM의 2026-05-20 SP1 보고서: JALR 완전성 문제와 형식 정리 전제. 현재 고정한 SP1 v6.4.0에 같은 문제가 남았다고 주장하지 않는다.

각 원문 링크와 절·쪽수는 해당 본문과 evidence 등록에 있다. 숫자 예제는 설명용 가정이며 원 논문 실험을 재현한 벤치마크가 아니다.
