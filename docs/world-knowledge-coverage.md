## 편집 축

### 철학: 질문과 논증의 선수 경로

1. 논증과 반례 — 결론이 따라오는가, 전제는 참인가
2. 지식과 정당화 — 맞힌 것과 안 것을 무엇으로 가르는가
3. 윤리 판단 — 결과·의무·성품이 충돌할 때 무엇을 비교하는가
4. 정치와 사회 — 자유·권리·정당성·분배를 어떤 기준으로 다루는가
5. 과학과 설명 — 관찰·가설·인과·모형이 어디까지 말하는가
6. 마음과 언어 — 경험·의미·의식·인공지능을 무엇으로 판정하는가

사상사는 이 질문 축을 배운 뒤 고대 지중해, 중국 제자백가, 인도 철학, 이슬람 철학, 근대 유럽, 아프리카·탈식민 사상의 시간과 장소를 교차해 읽는다.

### 역사: 방법과 사건의 두 경로

- 방법 경로: 기록자의 위치 → 숫자가 만들어진 방법 → 남은 자료에서 가능한 추론
- 세계사 1차 시간 경로: 고대 제국의 도로·세금·법 → 600~1500년 교역·종교·번역망 → 대양 정복·질병·은 → 혁명·시민권·산업 제국 → 세계대전·대공황·대중 국가 → 냉전·탈식민·세계화
- 다음 확장 경로: 농업·도시·국가 형성 → 종교·법·지식 기관의 장기 변화 → 지역별 정치·사회·생활사 → 금융화·디지털화·기후 위기

한 시대를 세계 전체의 한 단계로 표현하지 않는다. 동아시아·남아시아·서아시아·아프리카·유럽·아메리카·오세아니아의 서로 다른 속도와 연결을 시기마다 확인한다.

### 경제사: 생산·장부·권리의 시간축

1. 농업 잉여, 창고 장부, 세금과 국가
2. 도시·화폐·장거리 교역과 신용
3. 토지 권리·노동 의무·상업 조직
4. 대서양 노예제·식민지 수탈·세계 상품망
5. 산업혁명, 에너지, 임금과 도시 생활
6. 기업·은행·중앙은행·보험의 확대
7. 금본위제, 세계대전, 대공황, 브레턴우즈
8. 탈식민 개발, 복지국가, 냉전 경제
9. 1970년대 전환, 변동환율, 금융화와 세계 공급망
10. 디지털 플랫폼, 인구·기후·에너지 전환

## 깊이 판정

각 칸은 제목이나 열 개 절의 존재로 닫지 않는다. 다음 질문에 모두 답할 때만 설명된 것으로 표시한다.

- 작은 사례의 수치와 행위자를 끝까지 다시 쓰는가
- 원 사료·논문·공식 자료에 사례를 실제로 대입하거나 대조하는가
- 시기·지역·자료가 허용하는 주장 범위를 밝히는가
- 적어도 하나의 경쟁 설명이나 반례를 다루는가
- 독자가 다음 사례를 예측할 질문과 답 위치가 있는가
