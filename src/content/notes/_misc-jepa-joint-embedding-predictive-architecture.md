# JEPA (Joint Embedding Predictive Architecture)

## 한 줄 정의
픽셀을 직접 생성하지 않고, 이미지 특징을 압축해 놓은 '상징'의 미래를 예측하는 AI 구조입니다.

## 더 풀어 쓰면
기존의 AI(예: Diffusion 모델)는 이미지를 만들 때 "이 픽셀이 저 픽셀보다 어떻게 변할까?"를 하나하나 계산하며 픽셀 단위로 미래를 예측했습니다. 하지만 JEPA 는 그런 비효율적인 픽셀 단계를 건너뛰고, 이미지의 핵심 정보만 담은 **임베딩 (Embedding)** 공간에서 "앞으로 이 특징이 어떻게 바뀔까?"를 예측합니다. 이를 통해 시각적 인지 능력을 훨씬 더 효율적으로 학습하고, 로봇이 세상을 이해하는 방식에 혁신을 가져옵니다.

## 실제 예시
- **비교 예시 (Diffusion vs JEPA)**:
  - *Diffusion*: `Input Image` → `Pixel-by-Pixel Prediction` → `Output Image` (매우 느리고 계산 비용 큼)
  - *JEPA*: `Input Image` → `Encoder (Embedding)` → `Predictor (Future Embedding)` → `Loss Calculation` (픽셀 없이 특징만 예측)

- **구체적 작동 과정**:
  ```python
  #pseudo code for JEPA flow
  image = get_image()
  embedding = encoder(image)          # 이미지를 '특징 벡터'로 변환
  future_embedding = predictor(embedding) # "이 특징은 다음 프레임에서 이렇게 변할 거야"라고 예측

  # 손실 함수는 실제 미래 이미지의 임베딩과 예측된 임베딩을 비교하여 오차를 계산
  loss = compare(real_future_embedding, future_embedding)
  ```

## 헷갈리기 쉬운 것
- **Diffusion 모델**: 픽셀 단위로 이미지를 생성/변환하지만, JEPA 는 픽셀을 건드리지 않고 '특징'만 예측합니다. (생성 vs 예측)
- **Self-Supervised Learning**: JEPA 도 자기 지도 학습의 한 종류이지만, 구체적으로 "픽셀 재구성" 대신 "임베딩 공간에서의 예측"에 특화된 아키텍처입니다.

## 자료 정리: AMI Labs, World Labs의 월드모델 기술 분석

# JEPA 의 숨겨진 '액션 탐색' 전략: 디코더 없는 CEM 과 시뮬레이션의 한계

기존 픽셀 기반 월드모델이 "미래의 이미지를 그리는 것"에 집중했다면, AMI Labs 의 JEPA 기반 모델은 **"미래의 상징 (Symbol) 을 예측하여 최적의 행동을 찾는 것"**에 초점을 맞춥니다. 이 자료는 JEPA 가 단순히 특징을 압축하는 것을 넘어, **디코더 (Decoder) 가 아예 없는 구조**에서 어떻게 로봇이 행동을 결정하는지 그 독특한 메커니즘을 보여줍니다.

## 1. "그림을 그리지 않는" 예측의 역학
기존 방식 (Waymo, Genie 등) 은 미래 프레임의 픽셀 값을 예측하여 디코더로 되돌려 이미지를 생성합니다. 하지만 AMI Labs 의 V-JEPA 2 는 **이미지를 재구성하지 않습니다.** 대신, 현재 상태와 미래 상태를 '잠상 공간 (Latent Space)'에서 비교합니다.

> "픽셀을 직접 생성하지 않고, 이미지 특징을 압축해 놓은 '상징'의 미래를 예측하는 AI 구조입니다."

이 자료는 이 '상징'이 단순한 데이터가 아니라, **물리적 법칙과 상호작용에 대한 내재적 지식**으로 작동함을 강조합니다. Yann LeCun 은 LLM 이 언어적 패턴만 학습한다고 비판하며, "실제 세계를 이해하려면 시각적·물리적 인과관계를 직접 학습해야 한다"고 주장합니다. JEPA 는 이를 위해 픽셀 단위의 노이즈를 제거하고, 의미 있는 '잠상'만 남깁니다.

## 2. 디코더 없는 CEM 액션 샘플링: 행동 결정의 핵심
이 자료가 fundamental 에서 다루지 않은 가장 독특한 기술적 통찰은 **CEM (Cross-Entropy Method)** 활용법입니다. 일반적인 RL 은 복잡한 보상 함수를 필요로 하지만, JEPA 기반 모델은 다음과 같은 과정을 거칩니다.

1.  **액션 후보 생성:** 로봇이 취할 수 있는 다양한 액션 (회전, 전진 등) 을 무작위로 샘플링합니다.
2.  **예측 실행:** 각 액션에 대해 JEPA 가 "미래 잠상"을 예측합니다. 이때 디코더는 존재하지 않습니다.
3.  **비교 평가:** 예측된 미래 잠상과 현재 상태 잠상을 비교하여 **오차 (Loss)**를 계산합니다. 즉, "이 행동을 했을 때 목표 상태와 얼마나 가까워지는가?"를 이미지 없이 숫자만으로 판단합니다.
4.  **최적화:** 오차가 가장 적은 액션을 선택하여 실제 로봇에 적용합니다.

이는 **"그림을 그려서 확인하는 것이 아니라, 숫자 계산으로 미래를 검증한다"**는 점에서 기존 방식과 근본적으로 다릅니다. 이 방식은 컴퓨팅 자원을 아끼면서도 물리적 시뮬레이션의 정확도를 높일 수 있게 합니다.

## 3. 시뮬레이션의 한계와 '일반 직관'
자료는 JEPA 가 가진 실용성 한계도 지적합니다. 픽셀 기반 모델은 시각적 노이즈 (빛 변화, 배경 등) 에 강하지만, JEPA 는 **잠상 공간에서의 추상화 오류**가 발생할 수 있습니다. 예를 들어, 사물의 질감이나 색상이 왜곡될 경우 예측 결과가 틀릴 수 있다는 것입니다.

하지만 AMI Labs 는 이를 극복하기 위해 **"General Intuition"** 개념을 도입했습니다. 이는 단순히 데이터를 보는 것을 넘어, 사물이 어떻게 움직일지에 대한 **'직관적 물리 법칙'**을 학습하는 것입니다. Fei-Fei Li 의 World Labs 와 비교했을 때, World Labs 는 3D 공간 (NeRF/Gaussian Splatting) 을 구축하여 물체의 입체감을 살리는 반면, AMI Labs 는 **2D/3D 를 막론하고 '행동의 결과'에 집중**한다는 차이가 있습니다.

> "Yann LeCun 의 LLM 비판 어록: 언어 모델은 세상을 이해하지 못한다."

## 요약 및 보강 포인트
이 자료는 JEPA 가 단순히 '이미지를 압축하는 기술'이 아니라, **디코더를 배제하고 CEM 알고리즘으로 직접 행동을 탐색하는 '시뮬레이터'**임을 보여줍니다. fundamental 에서 다루지 않았던 **'액션 샘플링 과정에서의 수치적 평가'**와 **'시각적 노이즈 제거를 통한 물리 법칙 학습'**이라는 관점을 추가함으로써, JEPA 가 왜 로봇 제어에 더 효율적인지 구체적인 논리를 보강했습니다.

# JEPA 의 실전 구현: '디코더 없는' 예측과 시뮬레이션의 한계

기존의 픽셀 기반 월드모델이 "다음 프레임의 색상을 어떻게 그릴까?"에 집중한다면, **AMI Labs 가 제안하는 JEPA (Joint Embedding Predictive Architecture) 기반 Latent World Model**은 "이미지의 핵심 특징 (Latent) 이 어떻게 변할까?"에 집중합니다. 이 접근법의 가장 독특한 점은 **디코더 (Decoder) 의 부재**와 이를 활용한 **CEM (Covariance Matrix Adaptation) 액션 샘플링** 기법에 있습니다.

## 1. 디코더가 없는 예측의 역설
기존 방식은 예측된 Latent 를 다시 이미지로 복원 (Reconstruction) 하여 화질 저하를 방지해야 했습니다. 하지만 AMI Labs 의 V-JEPA 2 구조는 이 과정을 완전히 생략합니다.
> "디코더를 제거함으로써 모델은 픽셀의 노이즈나 세부적인 텍스처에 연연하지 않고, 물리 법칙과 공간적 관계라는 '본질'만 학습하게 됩니다."

이 구조에서 모델은 입력된 Latent 토큰을 바탕으로 미래 상태의 Latent 토큰을 직접 예측합니다. 만약 디코더가 없다면, 어떻게 이 예측이 실제 행동으로 이어질까요? 바로 **CEM 액션 샘플링**이 해결책입니다.

## 2. CEM 을 통한 액션 최적화
디코더가 없으므로 '이미지 생성'이라는 중간 단계 없이, **직접적으로 행동 (Action) 을 탐색**합니다.
1.  **샘플링**: 모델은 현재 상태에서 가능한 여러 가지 액션 시나리오를 무작위로 생성합니다.
2.  **예측**: 각 시나리오에 대해 JEPA 가 미래 상태의 Latent 를 예측합니다.
3.  **평가**: 예측된 미래 상태가 목표 (Goal) 에 얼마나 가까운지 점수화합니다.
4.  **최적화**: 점수가 높은 액션들의 분산 (Covariance) 을 줄이며 더 정밀한 방향으로 갱신합니다 (CEM 알고리즘 적용).

이 과정은 픽셀을 그려보는 것이 아니라, **"어떤 행동을 했을 때 목표 지점이 가장 명확해지는가?"**를 Latent 공간에서 직접 계산하는 방식입니다. 이는 계산 비용을 획기적으로 줄일 뿐만 아니라, 로봇이 복잡한 시각적 디테일에 매몰되지 않고 물리적 제어에만 집중하게 만듭니다.

## 3. Fei-Fei Li 의 대안: 3D Spatial World Model
반면, Fei-Fei Li 의 **World Labs**는 JEPA 와는 다른 길을 걷습니다. 이들은 픽셀 생성 대신 **NeRF 및 Gaussian Splatting** 기술을 기반으로 한 **3D Spatial World Model**을 구축했습니다.
*   **기술적 차이**: JEPA 가 '시각적 특징'을 압축해 미래를 예측한다면, World Labs 는 '3 차원 공간' 자체를 생성하여 시뮬레이터로 활용합니다.
*   **응용**: 'Marble' 프로덕트를 통해 로봇이 3D 환경을 이해하고 학습하는 데 초점을 맞춥니다. 이는 JEPA 가 가진 '상징적 추론'의 한계를 보완하여, 로봇이 실제 물리적 공간에서 작동할 때 필요한 깊이 정보와 기하학적 구조를 제공합니다.

## 4. JEPA 의 실용성과 비판적 관점
비록 효율적이지만, JEPA 기반 모델은 여전히 비판받습니다. 특히 **"학습 방법론"** 측면에서입니다. 픽셀을 직접 생성하지 않기 때문에, 모델이 학습한 Latent 가 실제 세계의 모든 변수를 포괄하는지 확인하기 어렵습니다 (Black Box 문제). 또한, Yann LeCun 이 지적했듯 LLM 기반 접근법과는 달리, JEPA 는 **"시각적 추론"에 특화되어 있어 언어적 추론이나 고차원적인 논리에는 약점**이 있을 수 있습니다.

그러나 AMI Labs 는 이러한 한계를 극복하기 위해 V-JEPA 2 를 통해 더 깊은 레이어와 더 넓은 컨텍스트를 다루며, **"픽셀 생성 없이도 강력한 월드 모델을 만들 수 있다"**는 것을 증명하고 있습니다. 이는 단순히 비디오를 만드는 것을 넘어, 로봇이 스스로 사고하고 계획하는 **'시뮬레이터로서의 월드'**로 가는 핵심 열쇠입니다.
