# Borrowed Chord

## 한 줄 정의
다른 조 (Key) 에서 가져와서 감정을 더 깊게 만드는 '빌려온' 화음입니다.

## 더 풀어 쓰면
원래 조 (Key) 에 없는 음을 일부러 섞어서, 갑자기 슬퍼지거나 신비로워지거나 강렬해지는 효과를 주는 기법입니다. 단순히 '다른 조로 바꾼다'는 것이 아니라, 원래 조의 틀을 유지하면서 '가끔씩' 다른 조의 코드를 섞어 쓰는 것이 핵심입니다. 이 기법은 재즈나 팝에서 클리셰를 깨고 감정의 깊이를 더할 때 필수적으로 사용됩니다.

## 실제 예시
가장 대표적인 예는 **C 메이저 (C Major)** 조에서 **C 마이너 (C Minor)** 코드를 빌려오는 것입니다. C 메이저에는 E(마이너 3 도) 가 없는데, 여기 갑자기 E♭을 넣어 슬픔을 표현합니다.

- **예시 1: C 메이저 조에서 C 마이너 빌리기 (I → i)**
  ```text
  진행: Cmaj7 → Cmin7 → Fmaj7 → G7
  효과: 밝은 C 코드가 갑자기 어두워지며 (Cmin7), F 코드로 넘어가는 감정의 전환이 극적으로 강조됨.
  ```

- **예시 2: C 메이저 조에서 F 마이너 빌리기 (IV → iv)**
  ```text
  진행: C → Fmaj7 → Fmin7 → G7
  효과: 평범한 F 코드가 Fmin7 로 바뀌며 (Bb 대신 B♭♭/A 가 들어감), G7 로 가기 전 긴장감을 극대화하여 해결감을 높임.
  ```

- **예시 3: C 메이저 조에서 A 마이너 빌리기 (vi → VI)**
  ```text
  진행: C → Am7 → Dm7 → G7
  효과: 원래 A 마이너 (Am7) 는 C 조의 자연음계지만, A 메이저 (A7) 를 빌려와서 (A♭ 대신 A 자연음 사용) 더 강렬한 도미넌트 느낌을 줌.
  ```
  *(참고: 위 3 번 예시는 '비트 빌리기'의 반대인 '메이저 빌리기'의 경우로, C 조에서 A 메이저 7 (A7) 를 빌려와서 G7 로 가는 '서브도미넌트' 효과를 줄 수도 있습니다. 가장 흔한 건 마이너 빌리기입니다.)*

## 헷갈리기 쉬운 것
- **모달 인터체인지 (Modal Interchange) vs 톤 빌로우 (Tonal Borrowing)**: 엄밀히 말하면 같은 개념을 지칭하지만, '모달 인터체인지'는 마이너/메이저 조의 모드 (Mode) 전체를 빌려온다는 뉘앙스가 강하고, 'Borrowed Chord'는 특정 코드 하나만 가져온다는 뉘앙스가 강합니다. (실무에서는 거의 동의어로 씁니다.)
- **모달 전조 (Modal Modulation) vs 빌려온 코드**: 모달 전조는 조 (Key) 를 완전히 바꾸는 것이지만, 빌려온 코드는 조를 바꾸지 않고 '일시적으로' 다른 색을 입히는 것입니다.
