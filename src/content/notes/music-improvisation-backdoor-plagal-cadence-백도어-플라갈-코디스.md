# 백도어 (Backdoor) / 플라갈 코디스 (Plagal Cadence)

## 한 줄 정의
'주음으로 가는 마지막 길'을 뜻하는, IV 화음이 I 화음으로 부드럽게 해결되는 '아멘' 같은 종결감의 진행입니다.

## 더 풀어 쓰면
플라갈 코디스 (Plagal Cadence) 는 성가 (그리스도교 찬양) 에서 '아멘'을 부를 때 쓰는 전형적인 진행 (IV → I) 으로, 종지감을 주지만 강렬한 '도미넌트'의 느낌보다는 차분하고 평온한 마무리를 줍니다.
이것이 재즈에서는 **백도어 (Backdoor)** 라고 불리는데, 이는 IV7 화음이 I7 화음으로 직접 가기보다는, IV7 → bVII7 → I7 같은 변주된 경로를 통해 '주음'으로 들어가는 독특한 하모닉 흐름을 의미합니다.
즉, 전통적인 '아멘'의 느낌을 재즈적으로 확장하거나 변형하여 사용하는 화성 기법입니다.

## 실제 예시
### 1. 전통적 플라갈 코디스 (Amen Cadence)
성가나 팝송에서 흔히 들리는, IV → I 로 끝나는 가장 단순한 형태입니다.
- **C Major 에서**: `Fmaj7` → `Cmaj7` (IVm7 → Imaj7)
  - *설명*: "아멘"을 부를 때처럼 F 화음이 C 화음으로 부드럽게 마무리됩니다.

### 2. 재즈 백도어 진행 (Backdoor Cadence)
재즈에서 C Major 를 C7 로 바꾼 후, IV7 와 bVII7 를 거쳐 I 로 들어가는 전형적인 패턴입니다.
- **C Major 에서**: `Fm7` → `Bb7` → `Cmaj7` (IVm7 → bVII7 → Imaj7)
  - *코드 분석*: Fm7(IVm), Bb7(bVII), Cmaj7(I). Bb7 화음이 C 화음으로 가는 '백도어' 역할을 하며, 특히 Bb 의 3 도 (D) 와 5 도 (F) 가 C 의 3 도와 5 도를 포함해 부드럽게 연결됩니다.

### 3. 'Christophe Changes' 포함 패턴 (IV-IVm-bVII-I)
사용자가 언급한 특정 패턴으로, IV 마이너와 VII 플랫을 거치는 복합적인 흐름입니다.
- **C Major 에서**: `Fmaj7` → `Fm6` → `Bb13` → `Cmaj9`
  - *코드 분석*: IV 마이너로 전환된 후 bVII13 가 I 로 해결되는 매우 세련된 재즈적 종결입니다.

## 헷갈리기 쉬운 것
- **정통 도미넌트 진행 (V-I)**: V-I 는 긴장감이 극도로 높아 강렬하게 끝나는 반면, 백도어/플라갈은 긴장감이 낮고 차분하게 끝납니다. "강한 결말" vs "부드러운 결말"의 차이입니다.
- **단순 IV-I vs 백도어**: 단순 IV-I 는 바로 연결되지만, 백도어는 보통 중간에 bVII(또는 bVI 등) 를 거쳐서 "우회"하는 경로를 통해 들어갑니다.

## 다음 개념

- **Secondary Dominant**: V-VI 나 V-II 처럼 특정 화음을 위해 임시로 도미넌트를 만드는 기법으로, 백도어의 '우회' 논리와 대비되는 '직접 타격' 방식입니다.
- **Modal Interchange**: 동명 모드에서 차용한 코드 (예: Fm6 를 F 마이너에서 가져옴) 를 사용하여 색상을 바꾸는 기법으로, 백도어의 Fm6 같은 코드 구성 원리를 이해하는 데 필수적입니다.
