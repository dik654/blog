# Parent Scale (부모 음계)

## 한 줄 정의
특정 음계나 모드가 '어떤 기본 틀 (장음계 등) 에서 파생되었는가'를 생각하며, 그 기본 틀의 음들을 모두 기억하는 사고방식입니다.

## 더 풀어 쓰면
재즈나 현대 음악에서 '모드 (Mode)'를 배울 때, 각 모드를 완전히 새로운 음계로 외우는 대신, 그 모드가 속해 있는 '큰 틀' (예: 도 리드 모드는 C 장음계의 일부) 로 생각하면 훨씬 효율적입니다. 이 개념은 특정 음계에서 나올 수 있는 모든 음을 미리 파악하여, 즉흥 연주 (Improvisation) 시 음계 밖의 음 (오염음) 을 피하고, 화성 진행에 맞는 음들을 빠르게 선별할 수 있게 해줍니다.

## 실제 예시
- **C 리드 모드 (Dorian) 의 사고**: C 리드 모드를 따로 외우지 않고, "C 리드 모드는 **C 장음계 (C Major)**의 2번째 음에서 시작되는 것"이라고 생각합니다. 따라서 C 리드 모드에서 나올 수 있는 모든 음은 C 장음계의 음 (C, D, E, F, G, A, Bb) 과 동일합니다.
  ```text
  C Dorian Scale = C Major Scale (음은 같음, 시작음만 다름)
  C Dorian: C, D, Eb, F, G, A, Bb  ← C Major: C, D, E, F, G, A, B (단, 3/7음만 다름)
  ```
  *적용*: C7 화음 위에서 즉흥 연주를 할 때, C 장음계 (C Major) 의 모든 음을 알고 있다면, 그중에서 C 리드 모드에 맞는 'Eb'와 'Bb'를 선택해 자연스럽게 연주가 가능합니다.

- **A 멜로딕 마이너 (Melodic Minor) 의 사고**: A 멜로딕 마이너 음계를 외울 때, "A 멜로딕 마이너는 A 장음계 (A Major) 의 3음에서 시작되는 것"이 아니라, "A 멜로딕 마이너는 **A 장음계**와 비슷하지만 3, 6, 7음이 반음씩 올라간 형태"라고 생각합니다. 하지만 '부모 음계' 관점에서는 A 멜로딕 마이너가 속한 '큰 틀'을 'A 장음계'가 아닌, **A 멜로딕 마이너 자체가 부모 음계**가 되어 그 안에서 파생된 모드 (예: A 리드 플레지아, A 리드 리디안 등) 를 다룰 때 사용합니다.
  ```text
  A Melodic Minor Scale: A, B, C, D, E, F#, G#
  A Lydian Dominant (3번째 모드): A, B, C, D, E, F#, G# (A Melodic Minor의 3번째 음에서 시작)
  ```
  *적용*: G7alt 화음 (G7 altered) 에서 즉흥 연주를 할 때, G7의 '부모 음계'로 **A 멜로딕 마이너**를 떠올립니다. G7의 음들을 모두 A 멜로딕 마이너의 음 (G, A, B, C, D, E, F#) 에서 찾으면, 'Bb' (b9), 'Eb' (b5) 같은 알터드 음들이 자연스럽게 나옵니다.

## 헷갈리기 쉬운 것
- **모드 (Mode) vs 부모 음계 (Parent Scale)**: 모드는 '시작음과 음의 순서'를 강조하는 개념이고, 부모 음계는 '그 모드가 속한 전체 음계 (음의 구성)'를 강조하는 개념입니다. (예: C 리드 모드는 'C에서 시작하는 Dorian'이지만, 그 부모 음계는 'C 장음계'입니다.)
- **상대적 vs 절대적**: 부모 음계 개념은 '상대적'으로, C 리드 모드가 C 장음계에서 파생되었다고 생각하지만, 실제 연주 시에는 C 리드 모드 자체의 음들을 절대적으로 사용한다는 점이 다릅니다.
