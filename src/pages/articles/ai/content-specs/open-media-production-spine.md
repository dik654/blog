# Open Media Production Spine

## Reader contract

The reader starts with a production discard condition, not a model ranking.
They choose exactly one sibling branch:

```text
Current production goal
  ├─ Image runtime
  │    └─ one model case
  └─ Video runtime
       └─ one model case
             ↓
       Workflow replay evidence
             ↓
       Parameter budget
             ↓
       Smallest sufficient adaptation
```

The Image and Video runtime articles are alternatives, not consecutive
prerequisites. Shared articles may appear in both authored paths, but the
active `?path=` context must preserve the chosen branch in the article rail
and previous/next controls.

## Article ownership

| Article | Owns | Does not own |
|---|---|---|
| `open-image-video-models` | discard condition, current official candidate boundary, branch and case choice | full architecture or workflow instructions |
| `image-model-runtime` | condition, latent, prediction, solver and decoder failure ownership for one image | one vendor's exact architecture |
| `video-model-runtime` | the Image runtime delta: time, motion, audio, memory and temporal evidence | a universal claim that every video model has every mechanism |
| model case | one versioned artifact's mechanism, rights and evidence boundary | the generic runtime |
| `open-model-community-workflows` | graph, artifact, environment, preprocessing, sampling and output replay manifest | model quality ranking |
| `open-model-workflow-parameters` | a controlled cost/quality hypothesis for numeric controls | universal presets |
| `open-model-finetuning-theory` | smallest sufficient intervention and regression gate | automatic license or quality approval |
| `stable-diffusion-open-models` | optional concrete SD1.x/SDXL/SD3.5 implementation baseline | the mandatory first step for every current model |

## Current case directory

Every case must answer an independent transfer question.

- Ideogram 4: can exact text and layout survive the condition path?
- Krea 2: how does a broad style distribution survive RAW to Turbo?
- Z-Image: what changes when efficiency and few-step artifacts are primary?
- Illustrious XL: what is inherited, explicitly changed, or still an
  experiment in a domain checkpoint?
- Wan2.2: which task family and sparse/dense runtime is actually selected?
- LTX-2.3: what changes when video and audio share a current pipeline?

FLUX.2 and Qwen-Image may remain current decision candidates without a new
leaf article until a distinct, source-backed transfer question is not already
owned by the ComfyUI edit or runtime articles.

## Hidden transfer checks

1. A reader selecting a five-second product video must never be sent through
   Image runtime as the next mandatory article.
2. A reader switching from Image to Video in the goal Viz must receive a
   branch-aware link, not only changed text.
3. A shared workflow article opened from the Video path must retain Video as
   the previous step and must not silently fall back to Image.
4. A new checkpoint must be classified as a current candidate, concrete case,
   optional baseline, or watchlist before it is placed in the hub.
5. Stable Diffusion must be reachable when U-Net/SDXL inheritance is needed,
   but it must not lengthen every modern DiT path.

## Visual contract

- The goal router changes discard condition, control surface, candidate,
  evidence boundary and the actual branch link.
- Branch choices use two visually equal bands; neither appears to be the next
  chronological step after the other.
- Model cases are prose-led rows with a concrete question and evidence
  boundary, not a benchmark table.
- Shared Viz controls are at least 44px, retain a stable comparison frame and
  change evidence rather than color alone.
- Mobile, tablet and desktop must have no document, Viz or KaTeX overflow.

## Source and stop rule

Current product/repository/model-card sources own current capabilities,
artifacts and licenses. Papers own mechanisms at their stated version.
Conceptual teaching equations must be labeled as such. Latent Diffusion
(2021) is the finite historical floor for this path; older work is optional
inside the foundation article, not another mandatory sidebar rung.
