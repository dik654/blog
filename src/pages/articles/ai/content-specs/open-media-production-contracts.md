# Open Media Production Contracts

## Reader promise

The reader starts with a current production target and can descend only as far as needed:

1. choose a goal by its discard condition;
2. read either the image or video runtime branch;
3. rejoin at workflow reproducibility;
4. turn parameters into compute and quality hypotheses;
5. choose the smallest adaptation that can express the required change;
6. descend to Latent Diffusion (2021), VAE, tensors, or signals only when a runtime question requires it.

This route is a fork and rejoin, not a mandatory linear tour. Stable Diffusion, Z-Image, Illustrious, LTX, Wan, and animation pages are optional evidence or implementation cases. They are not equal prerequisites.

## Private transfer problem

A studio must produce:

- a Korean package label with exact text and line breaks;
- an edit that preserves product geometry, logo, and brand color;
- a five-second product video with stable identity and optional synchronized audio;
- a local fallback on approximately 24 GB of GPU memory;
- a commercially valid deployment path;
- a replayable manifest with source, model, graph, environment, input transform, and sampling lineage.

The six core articles must provide enough insight to reject these invalid plans:

- treating an announced editable layer roadmap as a current feature;
- treating all variants in one model family as having the same license;
- treating `consumer GPU` as a 24 GB guarantee without a pinned configuration;
- treating a ComfyUI JSON or screenshot as a reproducible run;
- copying step, guidance, resolution, and frame values between incompatible prediction and solver contracts;
- starting full fine-tuning before prompt, control, reference, or LoRA has been ruled out;
- accepting a lower training loss or a cherry-picked sample without a regression and release gate.

## Current evidence boundary · as of 2026-07-21

- Ideogram 4.0: official release, 2026-06-03. Open weights under a commercial license; multilingual typography, bounding-box layout control, 2K output. Transparent layers are current; editable text and movable image layers are described as follow-up work.
- Krea 2: official technical report, 2026-06-23. Permissive weights and inference release; single-stream DiT, Qwen3-VL text encoder, style-reference system, prompt expander, multi-stage post-training.
- FLUX.2: official documentation. API and open-weight variants are distinct. Klein 4B is Apache 2.0, 9B uses the FLUX Non-Commercial License; distilled and undistilled base variants have different roles.
- Qwen-Image: official repository. Qwen-Image-2.0 is announced with long instruction support, native 2K, integrated generation/editing, and a lighter architecture. Do not silently transfer 2025 edit-checkpoint mechanics or weight availability to 2.0.
- Wan2.2: official repository. A14B is a high-noise/low-noise expert MoE; TI2V-5B is a dense model with a high-compression video VAE. Repository models are Apache 2.0; consumer-GPU claims remain configuration-specific.
- LTX-2.3: official open-source documentation. DiT-based joint audio-video generation, multimodal input, open weights, local execution, and duration/resolution conditional on configuration and hardware. The LTX-2 Community License requires a separate paid commercial license for entities with annual revenue of at least USD 10 million. API product tiers and code licenses remain separate contracts.

## Acceptance contract for the private problem

Thresholds are fixed on a human-reviewed gold fixture before model comparison. They are not changed after seeing candidates.

- Korean typography: normalize target and OCR output to Unicode NFC, require exact codepoint and line-break equality, verify glyph boxes remain inside the specified layout boxes, and add human glyph review for stylized OCR misses.
- Product identity: treat silhouette, logo placement, part count, and brand color as hard attributes. Calibrate any embedding threshold on labeled pass/fail examples and never use it as the only judge.
- Five-second video: repeat image gates at fixed frame intervals, then separately gate motion-compensated flicker, identity drift, and audio-event offset.
- 24 GB fallback: declare a safety margin, measure peak allocated/reserved VRAM, host RAM, and cold/warm latency across three runs, then reduce temporal/spatial tokens before changing kernels, tiling, precision, and offload one axis at a time.
- Commercial path: snapshot model-weight, code, custom-node/dependency, input-asset, and output-use terms independently.
- Replay: run the pinned manifest on a second machine; where bitwise equality is unavailable, require the output to pass the same task gates.

## Article ownership

### 1. Open media goal router

Owns current model evidence, product/API/open-weight/license boundaries, and the image/video branch decision. It does not teach denoising mathematics.

### 2. Image runtime

Owns prompt/reference encoding, latent compression, prediction target, solver, guidance/control/LoRA separation, VAE reconstruction, and stage-owned debugging.

### 3. Video runtime

Explicitly inherits the image runtime and adds temporal compression, condition modes, motion state, noise-regime MoE, joint audio-video scope, temporal defects, memory, and delivery.

### 4. Workflow audit

Owns graph semantics, artifact and environment locks, hidden preprocessing/postprocessing, custom-node security, API snapshot boundaries, and a replay manifest.

### 5. Parameter contract

Owns seed, schedule, solver, denoiser call count, guidance, latent shape, frames, relative compute budget, and family-specific response curves. Values are never universal presets.

### 6. Adaptation decision

Owns the intervention ladder, trainable scope, target-versus-retention objective, data and memory planning, regression, rollback, and release evidence. Family pages may contain commands, but this page owns the decision contract.

## Visual contract

- No tiny SVG pipeline, arrow maze, or horizontally scrolling diagram.
- Stable card/grid dimensions and `min-width: 0` at every responsive boundary.
- Controls use buttons, segmented modes, and sliders with visible state.
- Values that are illustrative are labeled illustrative and never presented as hardware measurements.
- Accent colors encode evidence, warning, and pass/fail rather than decorating every box.
- Every formula is rendered with KaTeX, carries Korean in-equation annotations, and is followed by a Korean `FormulaNote` explaining the whole expression and symbols.

## Source and author intent record

Every current claim has a dated primary source. The article authoring decision is also preserved:

- official claims narrow candidates;
- a private adversarial fixture decides whether the prose transfers to practice;
- marketing scope, architecture inference, and measured local behavior are not merged;
- current models sit at the top, while the minimal historical cutoff is Latent Diffusion (2021), not an unbounded walk into older generative history.

## Claude review decisions

Adopted after source comparison:

- make image and video sibling goal branches that rejoin at workflow reproducibility;
- state video inheritance explicitly;
- treat parameters as a cross-cutting contract;
- distinguish volatile current evidence from stable runtime principles;
- test the private studio scenario through memory, license, identity, text, temporal, and replay gates.

Rejected or corrected:

- a model comparison table, because the reader requested model-by-model narrative depth and tables hide claim boundaries;
- absorbing generic workflow audit into family pages, because external graph and environment reproducibility is an independent contract;
- assuming typography is primarily API-only, because current official Ideogram, Qwen, and FLUX materials require a variant-specific check;
- splitting LoRA into another mandatory prerequisite, because the core adaptation article can own the intervention decision and family pages can remain optional implementations.
