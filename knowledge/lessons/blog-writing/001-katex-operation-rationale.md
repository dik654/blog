# KaTeX 수식에는 연산 이유를 바로 붙인다

## 날짜
2026-06-05

## 문제
CLIP/Image RAG 글에서 KaTeX 수식 아래에 각 기호 설명은 붙었지만, `norm(f_theta(g_v(x_i)))`, `s(q,i)=cos(z_q,z_i)`, `z_q^T z_i / (||z_q||_2 ||z_i||_2)` 같은 연산을 왜 하는지 설명이 부족했다. 독자는 `norm`, `cos`, `||.||_2` 나눗셈이 모델 품질과 검색 결과에 어떤 의미를 갖는지 바로 알기 어렵다.

## 원인
수식 설명을 변수 glossary로만 처리하면 연산자의 목적이 빠진다. 특히 embedding 검색 수식에서는 벡터의 크기, 방향, 내적, 정규화가 검색 순위를 바꾸므로, "무엇을 계산하는가"뿐 아니라 "왜 이 연산이 필요한가"를 함께 설명해야 한다.

## 해결
블로그 작성 규칙에 KaTeX 수식 바로 아래 `FormulaNote` 또는 동등한 설명 블록을 붙이고, 그 안에 변수 뜻과 연산 이유를 함께 쓰도록 고정한다. 예를 들어 `norm(f_theta(g_v(x_i)))` 아래에는 길이 편향을 제거하고 방향 기반 비교를 만들기 위해 정규화한다는 설명을 붙인다. `cos(z_q,z_i)=z_q^Tz_i/(||z_q||_2||z_i||_2)` 아래에는 내적을 벡터 길이로 나누어 크기 효과를 제거하고 방향 유사도만 비교한다는 설명을 붙인다.

## 교훈
KaTeX 수식 설명은 항상 "기호 뜻 + 연산 이유 + 결과가 해석되는 방식"까지 포함한다. `norm`, `||.||`, `cos`, softmax, log, argmax, Top-K, reranking 같은 연산자가 나오면 독자가 "왜 이 연산인가"를 바로 이해할 수 있게 수식 바로 아래에 설명한다. 관련 개념: [[VisualEmbedding]], [[TopKSimilaritySearch]], [[CLIP]].
